A block toolset to create a wiki-like experience. Optimized for the Clouds and Spaceships theme.

== Description ==

CNS Wiki Suite adds a *wiki* custom post type with a card grid, infobox blocks, and an optional glossary with inline term tooltips.

* **Wiki post type** with its own archive, categories, and tags.
* **Wiki Contents block** — a responsive grid of wiki cards, filled manually or with the newest wikis.
* **Wiki Card block** — thumbnail, title, excerpt, terms, and link for a single wiki.
* **Infobox blocks** — a sidebar infobox with grouped rows for structured facts.
* **Glossary (opt-in)** — a glossary post type with archive, index block, and an inline editor format that renders tooltip definitions in content.

Settings live under **CNS → Wiki** when the Clouds and Spaceships theme is active: archive slug, sort order, wikis per page, grid defaults, infobox colours, a placeholder thumbnail for wikis without a cover image, and glossary options.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/cns-wiki-suite`, or install through the WordPress plugins screen.
2. Activate the plugin.
3. Configure via the CNS → Wiki settings tab (requires the Clouds and Spaceships theme; the blocks work on any block theme).

== Frequently Asked Questions ==

= Does deleting the plugin remove my wikis? =

No. Uninstalling removes the plugin's settings only. Wiki and glossary posts are your content and are kept; delete them manually if desired.

= Does it work with other themes? =

The blocks and post types work on any block theme. The settings tab and default single/archive templates are tailored to the Clouds and Spaceships theme.
